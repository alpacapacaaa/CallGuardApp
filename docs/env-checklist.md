# 실기기 Continuity 환경 구축 체크리스트 (P1-T1)

> **보류 (2026-08-10)**: MVP 스코프가 파일 재생 입력으로 변경되어 이 체크리스트는 더 이상 프로젝트 임계경로가 아니다(PRD.md §2, plan.md Phase 1 참조). 라이브 캡처(F-C4)를 재개할 때만 수행한다.

> 목적: R1 검증(P1-T3)에 앞서, iPhone 통화 미러링 오디오가 Mac에서 수신되는 환경을 구축하고 확인한다.
> **수행 주체: 운영자.** 에이전트는 체크리스트와 절차만 제공하고, 실기기 조작·권한 클릭·통화는 수행하지 않는다.
> 각 항목을 수행 후 `[ ]` → `[x]`로 표시하고, 비고란에 실측 값을 기록한다.

## 1. iPhone 통화 미러링(Continuity) 활성화

- [ ] iPhone: 설정 → 전화 → 다른 기기에서 통화 → **이 iPhone에서 통화 허용** 및 대상 Mac 허용 확인
- [ ] Mac: 시스템 설정 → (FaceTime/연속성 관련) 이 Mac에서 iPhone 통화 허용 확인
- [ ] 미러링 수신 확인: iPhone으로 테스트 전화 수신 시 Mac에서 벨소리/오디오가 들리는지
  - 비고(수신 확인 여부): ______________________

> 통화 미러링이 켜져 있어야 상대방 음성이 Mac의 **시스템 오디오**로 흘러들어 SCK 캡처 대상이 된다.
> 이 단계가 안 되면 P1-T3 진행 불가 — 여기서 막히면 STOP 보고 대상.
