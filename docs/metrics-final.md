## 운영자 판정 필요 사항

1. **G-2 해결됨(2026-08-11)** — 원인은 모델이 아니라 STT 청크 길이(2s→8s로 변경, CER 0.458→0.114). 상세: docs/stt-benchmark.md.
2. **G-3 중간 기준 통과(2026-08-11)** — RuleEngine이 공백 유무만 다른 텍스트를 다른 문자열로 취급해 미탐이 나던 버그(예: 룰 키워드 "안전계좌" vs STT 결과 "안전 계좌") 수정 → Recall 0.400→0.800. **잔여 1건(phishing-impersonation-01.wav)은 룰 키워드는 정확히 매칭됐지만 결합값(0.4186)이 경보 임계값(0.5) 미달** — 원인은 룰 가중치(0.25~0.3)가 전부 0.5 미만으로 설계돼 있어 룰 단독 매칭만으로는 어떤 카테고리도 "주의" 등급을 못 넘음(분류기 점수에 전적으로 의존하는 구조). 룰 가중치 상향 여부는 **G12(임계값 임의 조정 금지) 대상이라 운영자 지정 필요** — P3-T8 이터레이션으로 착수 가능.
3. **평가셋 실데이터 미확보** — M2–M5는 10건 스모크 수치로 통계적 신뢰 불가. 금감원 "그놈 목소리" 등 실데이터(P3-T1) 사용 여부·확보 경로 결정 필요.
4. **M8** — P4-T9는 운영자 전용 태스크, 에이전트가 대신 수행 불가. CHECKPOINT-4 완결에 필수.
